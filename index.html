Über dieses Quiz

Ein inoffizielles Quiz zum Lernen der Spielernummern des EHC Biel-Bienne, ohne Verbindung zum Club. Die Namen und Nummern stammen von ehcb.ch, Stand siehe Datum im Banner. Der Code wurde vollständig von einer KI geschrieben, im Gespräch mit dem Autor, der Wünsche formuliert und getestet hat. Auch die Sprüche am Ende sind von der KI.

  • Eine einzelne HTML-Datei mit CSS und JavaScript, wie es jeder Browser mitbringt. Keine Bibliotheken, keine externen Schriften.
  • Läuft komplett auf dem Gerät, auch offline. Es wird nichts geladen und nichts gesendet.
  • Keine Cookies, keine Speicherung, keine Statistik. Nach dem Neuladen beginnt alles von vorn.

Der Quelltext unten ist die komplette Datei, so wie der Browser sie geladen hat.

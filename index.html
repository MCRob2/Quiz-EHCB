Was ist das hier?

Ein inoffizielles Quiz zum Lernen der Spielernummern des EHC Biel-Bienne. Keine Verbindung zum Club. Namen und Nummern stammen von ehcb.ch, Stand siehe Datum im Banner.

Technik

  • Eine einzige HTML-Datei. Sonst nichts.
  • Benutzt nur HTML, CSS und JavaScript, wie es jeder Browser von Haus aus kann. Keine Bibliotheken, keine Frameworks, keine externen Schriften, keine Bilder.
  • Die Seite lädt nichts nach und sendet nichts. Sie funktioniert auch offline.

Daten

  • Keine Cookies.
  • Kein Tracking, keine Analytics, keine Statistik.
  • Nichts wird gespeichert, auch nicht lokal. Seite neu laden = alles weg.
  • Es gibt keinen Server, der etwas empfangen könnte.

Herkunft

Der gesamte Code wurde zu 100 % von einer KI geschrieben, im Dialog mit dem Autor. Der Autor hat Wünsche formuliert, getestet und Korrekturen verlangt, aber keine Zeile selbst geschrieben. Auch die Sprüche am Ende stammen von der KI.
